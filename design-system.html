Contrast

Light mode: Black text on a #FAF6F0 page (16.6:1). Dark mode: Neutral text on Black (14.9:1). The footer is Neutral on Orange (3.5:1). Orange is never a text colour; hovered links get an Orange highlight with Neutral text (3.5:1).

Light and dark mode

The moon and sun button in the navigation switches themes. The site follows the system setting until a visitor picks one, then remembers it. Both themes use the same palette; only the roles below change. Orange stays the same in both: frame, footer and link hover.
